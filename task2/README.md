# 任务 #2｜快速判断卡

把 MVP 0 抓到的真实抖音素材，快速判断「这条东西值不值得我继续花时间」。

## 原则

- 只使用真实证据：正文、作者、发布时间、互动数据、已加载评论、URL
- 禁止根据标题猜正文、根据点赞量猜成交、脑补评论
- 证据不足直接写「当前证据不足，无法判断」
- 判断由模型完成，代码只负责证据整理

## 快速判断卡的 5 个问题

1. 这条到底在讲什么？
2. 为什么有人愿意看？（核心注意力来源）
3. 评论区真正发生了什么？（需求/购买/质疑/反馈）
4. 对我有什么价值？（主价值 + 次价值）
5. 下一步是什么？（继续深拆 / 市场反馈雷达 / 素材库 / 选题池 / 观察 / 丢弃 / 证据不足）

## 价值排序

真实市场反馈 > 真实用户需求 > 真实商业反馈 > 可迁移方法 > 强选题信号 > 单纯播放量

## 文件

- `judge.py`：主入口，读 capture → 校验 → 评论去噪 → 输出卡片模板
- `validate.py`：证据完整性校验
- `comments.py`：评论去噪与粗分（关键词仅用于粗筛）
- `card.py`：卡片格式输出

## 使用

双击 `judge-latest.cmd`，直接看到最新一条 capture 的快速判断卡模板（证据已填充，判断由模型完成）。

或命令行：
```
python task2/judge.py [capture.json]
```
